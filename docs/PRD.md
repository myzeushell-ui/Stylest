# «Образ» — PRD и план фаз

## 1. Продукт

Персональный AI-ассистент по внешности и здоровью. Объединяет три модуля вокруг
единого «профиля себя» и надстройки **Style DNA**, которая всегда объясняет
**причину** рекомендации.

### User flows (MVP)
1. **Онбординг** → «Профиль себя»: цветотип, фигура, тип кожи/волос, цели, бюджет, lifestyle.
2. **Гардероб** → добавить вещь (фото + теги) → список → аналитика (cost-per-wear, пробелы) → мок-примерка.
3. **AI-стайлинг** → чат подбирает образ под погоду/повод и объясняет «почему».
4. **Бьюти** → дневник кожи/волос → AI-консультант + трекер средств + мок-анализ кожи.
5. **Фитнес** → цели → трекер активности → AI-подбор упражнений.
6. **Style DNA** → опросник → карта внешности → инсайты, «что докупить», `PurchaseImpactScore`.

### Экраны
Home, Profile, Wardrobe, WardrobeAnalytics, Beauty, Fitness, Chat (AI),
StyleDNA Hub, StyleDNASetup, StyleDNAResults, StyleDNAInsights, MissingItems,
HighImpactPurchases, BeautyDNA, BodyDNA.

### MVP vs v2
- **MVP:** локально-первый PWA (офлайн), мок-провайдеры, AI-чат через бэкенд-прокси
  (Claude или мок), полный Style DNA с прозрачными формулами.
- **v2:** живые провайдеры (Perfect Corp, Aiuta/FASHN, WB/Ozon API), живой
  self-hosted Supabase (Postgres + Storage + Auth), AI-интерпретация фото, шеринг
  образов, соцфичи.

## 2. Схема БД (Prisma/Postgres)

`User, SelfProfile, WardrobeItem, Outfit, BeautyEntry, BeautyProduct, FitnessGoal,
ActivityLog, StyleDNA, BeautyDNA, BodyDNA, PurchaseImpactScore, ChatMessage` —
у всех `id/userId/createdAt/updatedAt`. Полная схема: `apps/api/prisma/schema.prisma`.

## 3. PersonalRecommendationEngine — формулы (без «магии»)

Все score в шкале 0..100, веса `finalScore` зависят от типа товара. Код и тесты:
`packages/shared/src/scoring.ts`, `scoring.test.ts`.

| Score | Идея | Формула (кратко) |
|-------|------|------------------|
| `compatibilityScore` | совпадение с палитрой/стилем | базис 50; +35/+20/+15 за лучшие/базовые/акцентные цвета, −40 за худшие |
| `wardrobeImpactScore` | сколько образов усилит | доля сочетаемых вещей × 100; ×1.3 если закрывает пробел |
| `beautyCompatibilityScore` | совместимость с кожей/волосами | базис 60; +15 за рекомендованный ингредиент, −25 за нежелательный |
| `budgetFitScore` | вписывается в бюджет | ≤20% бюджета → 100; линейно до 10 при 100% |
| `lifestyleFitScore` | под образ жизни | 40 + 60 × (пересечение тегов / тегов вещи) |
| `finalScore` | итог | взвешенная сумма (веса по типу товара) |

`aiExplanation` собирается из сильнейшего и слабейшего факторов → всегда есть «почему».

## 4. Источники данных Style DNA (Фаза 6)

Каждое поле карты имеет явный источник (помечено в `apps/web/src/lib/buildDna.ts`):
- **[О]** опросник-онбординг (профиль + StyleDNASetup),
- **[М]** данные из модулей (гардероб, фитнес),
- **[Ф]** AI-интерпретация фото (на старте — мок),
- **[С]** синтез/правила (теория цвета и фигуры, движок).

Карта «живёт»: лайки/дизлайки и факт покупки сохраняются в `feedback` и уточняют её.

## 5. Монетизация (freemium) и первые пользователи

- **Бесплатно:** гардероб до N вещей, базовая аналитика, лимит AI-сообщений.
- **Премиум (₽/мес, ЮKassa/локальный эквайринг):** безлимит AI, инсайты Style DNA,
  виртуальная примерка, экспорт капсул.
- **Первые юзеры:** Telegram-каналы по стилю/моде, бьюти-блогеры, виральный хук
  «разбор гардероба за 5 минут».
